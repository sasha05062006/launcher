# Event Horizon Launcher

Personal minimalist gothic-futuristic Android launcher.

## Concept

- Pure black UI (`#000000`)
- Central **black hole** with neon event horizon (purple / cyan)
- Working **compass** that emerges from the black hole
- Thin gothic lines & runic accents
- Gestures, local smart suggestions, full privacy (no internet)

## Tech Stack

- Kotlin
- Jetpack Compose + Material 3 (heavily customized)
- DataStore for preferences
- Sensors for real compass
- minSdk 26+, targetSdk 35/36
